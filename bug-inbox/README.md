# bug-inbox

Bugs in Legion, from anyone: Joe, a commander, an operator, a strategist.

To post one, copy [TEMPLATE.md](TEMPLATE.md) to a new file in this folder named
`YYYY-MM-DD-short-slug.md`, for example `2026-10-23-finish-stops-batched-session.md`.
Use one file per bug. Fill in what you know, delete sections that don't apply, and
don't edit other people's bugs.

From another folder, the full path is
`~/@/1_Projects/agent_orchestration/legion/bug-inbox/`.

When a bug is fixed, its file moves to `bug-inbox/fixed/` with the fixing
commit added under **Status**.
