# Legion demo — doctrine

This squad paints one mural, described in `brief.md` in the project folder. Read it first.

- Only commander starts or stands down positions. Operators hand off with the legion MCP tool `handoff`.
- Painters only write their own tile file, `tiles/tile-<tile>.svg`. The critic only reads tiles. Nobody edits `brief.md`.
- Keep messages short. This is a demo: someone is watching the grid, so say what you're doing in a line.
- No git commits, no network, nothing outside this folder.
